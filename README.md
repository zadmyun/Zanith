# Zanit 1.2.1

Zanit é um cliente personalizado de Remote Play para Windows, baseado no código aberto do chiaki-ng Canary.

Esta versão inclui interface em Português (Brasil), integração local com DLSS 5/ReShade, indicador de disponibilidade do DLSS 5 e acesso direto ao canal oficial do Zanit no YouTube.

## Windows

Consulte [`BUILD_WINDOWS.md`](BUILD_WINDOWS.md). O projeto inclui o fluxo para gerar o pacote portátil Windows x64 e o instalador Inno Setup.
