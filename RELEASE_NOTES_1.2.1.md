# Zanit 1.2.1

Esta atualização consolida a identidade correta do aplicativo como **Zanit** e traz os ajustes solicitados para a interface e o instalador.

## Novidades

- Integração local com **DLSS 5/ReShade**, com indicador "DLSS 5 PRONTO" na tela principal.
- Novo botão compacto do YouTube, com a identidade visual do canal e o texto "INSCREVA-SE NO CANAL".
- Tradução completa para Português (Brasil) das janelas iniciais de arte da Steam e conexão Remote Play via PSN.
- Correção do nome **Zanith** para **Zanit** no aplicativo, nos recursos, nos scripts de compilação e no instalador.
- Instalador Windows x64 atualizado para a versão 1.2.1.

## Downloads

- `Zanit-1.2.1-Setup.exe`: instalador para Windows x64.
- O código-fonte desta versão está disponível automaticamente nos arquivos `.zip` e `.tar.gz` da release.
